# Principles of Neural Superposition

Neural networks represent features as directions in activation space.
When the number of features exceeds the dimension of the space, features are packed in superposition · an almost-orthogonal configuration.
This allows more concepts than neurons to be represented simultaneously.

Here is the mathematical formulation of superposition:
Given an activation vector $x \in \mathbb{R}^d$ and feature directions $w_i$, the representation satisfies:
$\langle w_i, w_j \rangle \approx 0$ for $i \neq j$.

Linear probes can decode features from activations using standard dot products.
The geometry of superposition determines how interference between features is minimized during inference — a crucial design trade-off.

## Probing and Sparse Representations

Features are often sparsely active across typical datasets.
Because only a few features activate at any given time, interference between non-orthogonal directions remains low.
Probing techniques measure the presence of these sparse directions across hidden layers.

Sparse coding and dictionary learning allow practitioners to decompose dense activation vectors into distinct, interpretable monosemantic components.
Each dictionary element corresponds to a recognizable semantic property in the input domain.
Through this lens, superposition is not merely noise, but an efficient compression mechanism employed by gradient descent.

## Mechanistic Circuits and Feature Absorption

When features are learned in superposition, downstream layers must disentangle them to perform non-linear operations.
Attentional circuits and multilayer perceptrons act as filters and routing mechanisms across the network depth.
In some cases, multiple redundant features collapse into a single unified representation, a phenomenon known as feature absorption.
